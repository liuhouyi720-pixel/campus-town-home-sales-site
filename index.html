How the medians are calculated

Each median is the middle sale price for a city and state. For an even number of sales, it is the average of the two middle prices. Medians are rounded to the nearest whole US dollar, with half dollars rounded up.

Following the data description sheet, prices below $1,000 are excluded. All prices of $1,000 or more are included, including high outliers. Each dataset row is kept as a separate sale; repeated street addresses are not removed. No filters use property type, size, or listing dates.

These are completed sales in the dataset collected in March 2026. Values were reported by the collection source and have not been verified against county records. Read the data description or download the source CSV.
